## 📌 项目简介

**Shizuku Sam** 将原生 **Shizuku 特权服务** 与专为三星 Galaxy（One UI）深度定制的 **硬件性能调度、充电保护、后台休眠与分应用刷新率规则** 整合为一体。

全应用采用 **底部三栏毛玻璃悬浮导航（`Shizuku` · `性能硬件` · `应用规则`）** 与 **Miuix 卡片/弹窗组件**，所有功能所见即所得，无需安装多个零散工具。

## ✨ 真实界面功能一览（与 App 100% 对应）

### 一、Tab 1：`Shizuku`（特权服务与无线配对）

1. **主状态卡片 (`Shizuku Sam`)**
   - **未运行状态**：显示当前无线调试端口探测状态，提供一键 **`无线调试启动`** 按钮。
   - **运行中状态**：实时显示 **服务版本**、**运行模式（`ROOT 模式` / `ADB 模式`）** 与 **已授权应用数量**，提供：
     - **`管理已授权应用`**：管理第三方应用的 Shizuku 授权。
     - **`终端 (rish)`**：导出并在终端应用中执行高权限 Shell。
     - **`停止服务`**：独立 Miuix `WindowDialog` 确认弹窗安全停止服务。
2. **`无线调试配对`（未运行时显示）**
   - **`免输入自动配对`**：开启无障碍服务后，系统弹出无线调试配对码时自动识别并填入完成配对，告别分屏手输 6 位数字。
   - **`无线调试配对向导`**：查看分步配对教程或手动输入 6 位配对码。
   - **`开发者选项`**：一键直达系统「开发者选项 -> 无线调试」页面。
3. **`更多启动方式` / `管理与备用通道`**
   - **`通过 Root 启动` / `通过 Root 重新启动`**：适用于已获取 Root（Magisk / KernelSU / APatch）的设备，免电脑免配对一键直启。
   - **`连接电脑启动` / `电脑端 ADB 启动命令`**：查看并复制电脑端 `adb` 启动脚本指令。
   - **`重连调试`**（ADB 运行时显示）：重新扫描本地回环无线调试端口并刷新 ADB 连接。

### 二、Tab 2：`性能硬件`（系统调度与硬件增强）

#### 1. `调度档位`（三档一键切换）
- **`系统默认`（日常均衡）**：恢复官方标准调度与自适应刷新率，清除所有额外脚本与限频，日常稳定均衡。
- **`省电自适应`（续航优先）**：开启系统轻度省电限制，同时强制解锁 **120Hz 高刷自适应 + 快速休眠**，解决三星原厂开启省电模式锁死 60Hz 的痛点。
- **`游戏满血`（满血释放）**：锁定 CPU/GPU 满血性能调度与极速触控响应，放宽刷新率限制，游戏满帧不降频。

#### 2. `硬件与体验增强`
- **`旁路供电 (游戏直供电)`**：边充边玩时绕过电池直接为主板供电，降低机身发热并保护电池寿命（需连接支持 PPS 协议的充电器且电量 ≥ 20%）。
- **`充电上限保护`**：右侧开关直接启停，点击卡片行弹出 Miuix `WindowDialog` 自定义 **充电上限 (%)** 与 **恢复充电 (%)** 阈值（内置 `80/75 日常`、`85/80 均衡`、`90/85 出行` 三档预设，支持恢复默认）。
- **`游戏自动高刷加速`（`v13.8.2` 支持按游戏独立指定档位）**：
  - 识别前台游戏自动接管高刷与性能模式，退出游戏后**自动按进入前的快照恢复原日常模式**。
  - 点击进入二级配置页，除设置**全局默认目标模式**外，还可**为列表中的每一款游戏单独指定档位**：
    - **`跟随全局默认`**
    - **`系统默认 (解除省电限频·不发热)`**：适合平时开「省电自适应」的轻中度游戏玩家，进游戏仅解除省电 CPU 限频、不强开满血，兼顾流畅与清凉。
    - **`游戏性能模式 (满血释放)`**：适合大型重度 3D 游戏。
    - **`省电自适应高刷 (省电+120Hz)`**：适合棋牌/文字类超轻度休闲游戏。
- **`实时 FPS 帧率浮窗`**：在屏幕左上角显示 SurfaceFlinger 纳秒级实时帧率与实时功耗。
- **`户外高亮模式`**：强光或阳光直射下临时激发屏幕最高物理亮度（HBM），并支持通知栏快捷磁贴一键开关。
- **`电池运行信息与健康度`**：点击弹出 Miuix `WindowDialog` 实时直读当前电量、温度、充电状态、充放电电流、电压、**电池循环次数**与**三星原厂真实健康度 (%)**。
- **`应用冷启动加速与清理`（`v13.8.1` 支持按应用独立编译）**：
  - 支持 **`全部第三方应用`** 或 **`勾选指定应用`** 执行 ART 预编译加速。
  - 提供三种编译模式：**`speed`（满血机器码编译，彻底消除冷启动卡顿）**、**`speed-profile`（按配置文件预编译）**、**`--reset`（清理重置编译产物）**，以及一键清理系统冗余缓存。

#### 3. `后台与深度休眠`
- **`后台进程休眠（墓碑）`**：启用 Android 原生 Freezer 冻结后台缓存进程，防止后台偷跑 CPU。
- **`熄屏深度休眠参数`**：熄屏后快速进入深度 Doze 睡眠；点击此行可进入二级页面自定义休眠步进参数与维护窗口间隔。
- **`限制后台自启`**：拦截后台广播偷起常驻服务与链式关联互拉，保持后台纯净。
- **`限制后台定位`**：将后台应用定位请求间隔限制为 30 分钟，降低待机耗电。
- **`限制扫描与同步`**：关闭后台隐式 Wi-Fi / 蓝牙 / 附近设备扫描与无用自动同步。

#### 4. `系统维护与拓展`
- **`强制所有应用分屏/小窗`**：解除应用窗口限制，让所有应用均支持分屏与多任务悬浮小窗。
- **`待机异常唤醒排查`**：智能排查后台频繁唤醒与异常耗电应用，支持一键压制。
- **`极客实验室`**：
  - **`解除受限设置`**：一键通过特权指令为应用开启 `ACCESS_RESTRICTED_SETTINGS`，解决 Android 13+ 无障碍「受限设置」灰显拦截。
  - **`后台保活白名单`**：管理 Doze 深度休眠白名单应用，防止核心即时通讯漏消息。
  - **`系统环境快速诊断`**：一键检测当前特权通道、无障碍服务、旁路供电节点等底层状态。
- **`恢复系统默认`**：一键清除所有已生效的调度、省电、刷新率及系统调优设置，完全交回官方系统默认接管。
- **`使用手册与帮助`**：查看工作原理、使用指南与排错说明。

---

### 三、Tab 3：`应用规则`（分应用刷新率规则）

1. **`前台感知与即时切换`**：基于无障碍服务实时检测前台活动应用并瞬时切换对应刷新率规则（未开启时提供显著提示与一键跳转开启按钮）。
2. **`常用场景预设`（2×2 快捷胶囊）**
   - **`日常自适应` (`10~120Hz`)**
   - **`视频节能` (`60Hz`)**
   - **`阅读护眼` (`10~60Hz`)**
   - **`游戏极速` (`120Hz`)**
3. **`应用规则设定`**
   - 从已安装应用中选择目标应用，配置 **`自适应刷新率`** 开关、**`最高刷新率`（`120Hz` / `90Hz` / `60Hz` / `48Hz`）** 与 **`最低刷新率`（`60Hz` / `48Hz` / `30Hz` / `24Hz` / `10Hz`）**，随时保存或删除。
4. **`已生效的应用规则`**：清晰列出所有已配置应用及其刷新率区间标签，支持点击回填编辑、单条删除或 **`清空全部规则`**。
5. **`高刷进阶与功耗校准`**
   - **`为什么抖音等流媒体锁定 60Hz？`**：点击 **`前往开发者选项`**，配合无障碍服务自动滚动定位至三星「开发者选项 -> 更多设置 -> 停用应用兼容性策略 (`Disable app compatibility policies`)」，彻底解锁抖音、B站等流媒体 120Hz 高刷。
   - **`LTPO 自适应降频校准`**：点击 **`激活自适应降频`**，激活 1Hz~120Hz 硬件级自适应并清理残留锁频，降低画面静止时的待机功耗。

- **JDK**：Java 21
- **Android SDK**：`compileSdk 36` / `targetSdk 36` / `minSdk 26`

