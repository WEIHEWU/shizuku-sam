## 📌 项目简介

**Shizuku Sam** 将原生 **Shizuku 特权服务** 与专为三星 Galaxy（One UI）定制的 **系统调度与硬件增强、后台与深度休眠、分应用刷新率规则** 整合为一体。

全应用（一级页面、二级页面、三级页面及所有弹窗）全面统一采用 **Miuix (`top.yukonga.miuix.kmp`) 界面组件体系**、**底部三栏毛玻璃悬浮导航（`Shizuku` · `性能硬件` · `应用规则`）**、**One UI 9 统一模态架构（二级/三级菜单 100% 弹窗浮层化 + 弹窗内平滑推入导航，主仪表盘与底部 Dock 永驻不闪烁）** 以及 **按需展开说明交互（默认单行极简主标题 + 长按单行展开/收起说明 + 顶部 `显示说明 / 隐藏说明` 胶囊开关）**。以下所有卡片名称、开关文案、按钮与二级页面均与当前 `v13.8.18` 真实界面逐字对应，并全面百分之百深度适配 **Samsung One UI 9 / Android 17**。

## ✨ 真实界面与二级页面完整对照

### 一、Tab 1：`Shizuku`（无线配对启动与特权服务通道）

1. **主状态卡片 (`Shizuku Sam`)**
   - **未运行（`待激活`）**：显示当前无线调试环境或本地配对端口状态，底部提供 **`无线调试启动`** 按钮。
   - **运行中（`Root / ADB · v13.x`）**：三格磁贴展示 **`服务版本`**、**`运行模式`（`ROOT 模式` / `ADB 模式`）**、**`已授权应用`**，并提供三个操作按钮：
     - **`管理已授权应用 (N 个已授权)`**：进入应用授权管理列表。
     - **`终端 (rish)`**：导出 `rish` 脚本，在终端应用中直接使用高权限 Shell。
     - **`停止服务`**：弹出 Miuix `WindowDialog` 确认弹窗安全停止 Shizuku 服务。
2. **`无线调试配对`（服务未运行时显示）**
   - **`免输入自动配对`**：开启无障碍服务，弹出配对码时自动输入完成配对。
   - **`无线调试配对向导`**：查看配对步骤教程或手动输入 6 位配对码。
   - **`开发者选项`**：直达系统设置，开启「无线调试」以启动服务。
3. **`更多启动方式`（服务未运行时显示）**
   - **`通过 Root 启动`**：适用于已获取 Root 权限设备，免电脑免 Wi-Fi 一键直启。
   - **`连接电脑启动`**：手机通过 USB 连接电脑，在命令行运行脚本激活。
4. **`管理与备用通道`（服务运行中时显示）**
   - **`重连调试`**（仅 ADB 模式显示）：重新扫描本地回环无线调试端口并刷新 ADB 令牌连接。
   - **`通过 Root 重新启动`**：切换为 Root 权限模式运行服务。
   - **`电脑端 ADB 启动命令`**：在电脑终端直接运行 `adb` 脚本激活。

### 二、Tab 2：`性能硬件`（系统调度与硬件增强）

#### 1. `调度档位`（三档点亮式胶囊）
- **`系统默认`（`日常均衡`）**：恢复官方标准调度与自适应刷新率，清除所有额外脚本与限频，日常稳定均衡。
- **`省电自适应`（`续航优先`）**：开启系统轻度省电限制，但解锁 120Hz 高刷自适应 + 快速休眠，耗电极低且滑动丝滑。
- **`游戏满血`（`满血释放`）**：锁定 CPU/GPU 满血性能调度与极速触控响应，放宽刷新率限制，游戏满帧不降频。

#### 2. `硬件与体验增强`
- **`旁路供电 (游戏直供电)`**：边充边玩绕过电池直接为主板供电，机身不发热、保护电池寿命（需连接支持 PPS 协议的充电器且电量 ≥ 20%）。
- **`充电上限保护 (80% / 75%)`**（带 `调参 ›` 标签）：
  - 右侧开关直接启停充电保护；
  - 点击此行弹出 Miuix `WindowDialog` 顶层弹窗：内置 **`80/75 日常`**、**`85/80 均衡`**、**`90/85 出行`** 三档快捷预设，支持手动输入 **`充电上限 (%)`** 与 **`恢复充电 (%)`**，以及 **`恢复默认`** 与 **`应用并开启`**。
- **`游戏自动高刷加速`**（带 `选游戏 ›` 标签，点击进入二级页面 **`游戏模式切换`**）：
  - **`游戏模式自动切换`**：主开关 **`启用游戏自动切换`**，识别前台游戏自动接管高刷与性能，离开即刻按进入前的快照还原日常模式。
  - **`默认进游戏目标模式`**：可选 **`系统默认`** / **`省电自适应高刷`** / **`游戏性能模式`**（作为未单独指定游戏的全局默认档位）。
  - **`切到后台保持时间`**：可选 **`30 秒`** / **`60 秒 (推荐)`** / **`120 秒`**。
  - **`游戏名单`（`v13.8.2` 支持按游戏独立指定档位）**：
    - 提供 **`添加游戏`**、**`添加到快捷栏`**（添加系统「游戏模式」快捷磁贴）、**`清空名单`** 按钮；
    - 已添加的每款游戏右侧均带有独立模式胶囊（**`系统默认 ▾`** / **`性能模式 ▾`** / **`省电高刷 ▾`**），点击可为该游戏单独指定：
      1. **`跟随全局默认`**
      2. **`系统默认 (解除省电限频·不发热)`**（适合日常开「省电自适应」时玩轻中度游戏，仅解除省电 CPU 70% 限频，不强开满血、不发热）
      3. **`游戏性能模式 (满血释放)`**（适合大型重度游戏）
      4. **`省电自适应高刷 (省电+120Hz)`**（适合超轻度休闲游戏）
- **`实时 FPS 帧率浮窗`**：在屏幕左上角显示 SurfaceFlinger 纳秒级零延迟实时帧率与功耗。
- **`户外高亮模式`**：强光或阳光直射下临时突破常规亮度上限，阳光下清晰可见。
- **`电池运行信息与健康度`**（带 `实时直读` 标签）：点击弹出 Miuix `WindowDialog` 顶层可滚动弹窗，实时读取电量、温度、充电状态、电流、电压、循环数、三星原厂健康度等硬件信息，支持 **`刷新数据`**。
- **`应用冷启动加速与清理`**（点击进入二级页面 **`应用启动加速`**）：
  - 卡片 1 **`ART 机器码预编译加速`**（`v13.8.7` 方案 A 体验升级，支持后台前台服务 + 通知栏/状态栏实时变动进度条 + WakeLock 防杀保活）：提供四个操作按钮——
    - **`自选应用编译`**（`v13.8.10` 方案 A 顶部分栏升级）：弹出应用挑选窗口，顶部采用 One UI 9 风格分段选择器（Segmented Tabs）划分 **`⚡ 未编译 (N)`** 与 **`✅ 已编译 (M)`** 双分类标签页，支持防误触与独立勾选；自由选择 **`热点极速 (默认推荐)` (`speed-profile`)**、**`全量编译` (`speed`)** 与 **`重置缓存` (`--reset`)**，精准区分 **`用户 (N)` / `全部 (N)` / `系统 (N)`**，展示应用真实图标与已编译状态徽标，弹窗支持点击 **`转到后台`**；
    - **`优化系统与桌面`**：对桌面 Launcher、SystemUI 及核心系统组件执行热点极速优化，桌面滑动与手势即刻丝滑；
    - **`全部应用极速优化`**：对全机已安装应用批量执行热点极速优化，彻底告别冷启动等待；
    - **`清除编译缓存`**：清除已生成的机器码编译缓存，恢复系统默认初始状态。
  - 卡片 2 **`应用缓存与空载进程清理`**：点击 **`立即清理释放`**，执行 `pm trim-caches` 与 `am kill-all` 释放应用临时缓存与后台空载进程。

#### 3. `后台与深度休眠`
- **`后台进程休眠（墓碑）`**：启用 Android 原生 Freezer 冻结后台缓存进程，防止偷跑 CPU。
- **`熄屏深度休眠参数`**（带 `调参 ›` 标签，点击进入二级页面 **`熄屏深度休眠`**）：
  - 主开关 **`开 / 关`**；
  - 维护设置：**`无需维护`** 开关（节省最多的电池）+ **`初始维护窗口间隔`** 滑动条（`10 分钟 ~ 120 分钟`）；
  - **`管理电池使用`** 卡片：包含 **`检查当前待机状态`**、**`待机异常唤醒排查`**、**`后台保护名单`**、**`最近待机记录`**、**`管理电池使用量`** 五项入口。
- **`限制后台自启`**：拦截后台广播偷起常驻服务与链式关联互拉，保持后台纯净。
- **`限制后台定位`**：将后台应用定位请求间隔限制为 30 分钟，降低待机耗电。
- **`限制扫描与同步`**：关闭后台隐式 Wi-Fi / 蓝牙 / 附近设备扫描与无用同步。

#### 4. `系统维护与拓展`
- **`强制所有应用分屏/小窗`**：解除窗口限制，让所有应用均支持分屏与多任务悬浮小窗。
- **`待机异常唤醒排查`**（点击进入二级页面）：
  - 提供 **`启用待机异常护栏`** 主开关、**`开始扫描`**（读取耗电、闹钟与待机桶排行生成异常候选建议，支持 **`一键添加建议项`**）以及 **`护栏名单`** 管理，精准抑制后台唤醒锁与过度闹钟。
- **`极客实验室`**（点击弹出三项工具菜单）：
  - **`解除受限设置`**：通过特权指令直接开启 `ACCESS_RESTRICTED_SETTINGS`，解除 Android 13+ 无障碍「受限设置」拦截；
  - **`后台保活白名单`**（进入 **`后台保护名单`** 页面）：支持按 **`全部` / `用户应用` / `系统应用`** 筛选与搜索，逐应用开关 Doze 白名单保护或后台限制；
  - **`系统环境快速诊断`**：一键检查核心特权通道、无障碍服务与旁路供电硬件节点支持状态。
- **`恢复系统默认`**：一键清除所有已生效的调度、省电、刷新率及系统调优设置，完全交回官方系统默认接管。
- **`使用手册与帮助`**：查看工作原理、使用指南与排错说明。

### 三、Tab 3：`应用规则`（分应用刷新率规则）

1. **`前台感知与即时切换`**：基于无障碍服务实时检测前台活动应用并瞬时切换对应规则（显示 `服务运行中` 或 `服务未开启 (功能锁定)`，未开启时提供 **`前往开启无障碍`** 按钮）。
2. **`常用场景预设`（2×2 点亮式胶囊）**
   - **`日常自适应` (`10~120Hz`)**
   - **`视频节能` (`60Hz`)**
   - **`阅读护眼` (`10~60Hz`)**
   - **`游戏极速` (`120Hz`)**
3. **`应用规则设定`**
   - **`点击选择目标应用`**：从已安装应用中选择目标应用；
   - **`自适应刷新率`** 开关：开启时在最低与最高刷新率区间动态调节，关闭时锁定在最高刷新率固定输出；
   - **`最高刷新率`**（Miuix `WindowDropdownPreference` 顶层下拉菜单）：`120Hz` / `90Hz` / `60Hz` / `48Hz`；
   - **`最低刷新率`**（自适应开启时显示）：`60Hz` / `48Hz` / `30Hz` / `24Hz` / `10Hz`；
   - **`保存此规则`** / **`删除此规则`**。
4. **`已生效的应用规则 (N)`**：展示所有已配置应用的刷新率区间标签，支持点击回填编辑、单条 `✕` 删除或 **`清空全部规则`**。
5. **`高刷进阶与功耗校准`**
   - **`为什么抖音等流媒体锁定 60Hz？`**：点击 **`前往开发者选项`**，跳转开发者选项并配合无障碍自动滑动至底部「更多设置」开启「`Disable app compatibility policies`（停用应用兼容性策略）」，解锁流媒体 120Hz 高刷。
   - **`LTPO 自适应降频校准`**：点击 **`激活自适应降频`**，激活 1Hz~120Hz 硬件级自适应，清理残留锁频，降低桌面与应用静止功耗。

### 四、快捷设置磁贴与右上角「设置」

- **系统通知栏快捷设置磁贴（Quick Settings Tiles）**：
  - **`游戏模式` 磁贴**：在通知栏一键切换 `系统默认` / `省电自适应` / `游戏满血`。
  - **`户外模式` 磁贴**：在通知栏一键开关户外最高物理亮度。
- **右上角 `设置` 页面 (`SettingsGlassScreen`)**：
  - **`启动与服务常驻`**：`开机启动（root）`、`Watchdog 守护服务`、`无线启动后保留 ADB TCP 模式`、`ADB TCP 端口`。
  - **`界面外观与主题`**：`深色主题`（跟随系统 / 始终开启 / 始终关闭）、`黑色夜间主题`（纯黑色主题）、`使用系统主题颜色`（Android 12+）。
  - **`语言与国际化`**：支持跟随系统、简体中文、繁體中文、English 等多语言切换。
